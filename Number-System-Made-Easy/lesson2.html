Binary Number System

Learn binary digits, base two and place values.

LEARN THE CONCEPT

Key idea

Binary uses only 0 and 1. Each position is a power of two, moving right to left: 1, 2, 4, 8, 16 and so on.

WORKED EXAMPLE

1011₂ = 1×8 + 0×4 + 1×2 + 1×1 = 11₁₀.
