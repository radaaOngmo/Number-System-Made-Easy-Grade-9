Binary to Decimal

Use positional values to convert binary numbers to decimal.

LEARN THE CONCEPT

Key idea

Multiply each binary digit by its positional power of two and add the results.

WORKED EXAMPLE

1101₂ = 1×8 + 1×4 + 0×2 + 1 = 13₁₀.
