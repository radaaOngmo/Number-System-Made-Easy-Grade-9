Introduction to Number Systems

Understand what a number system is and why computers use different bases.

LEARN THE CONCEPT

Key idea

A number system is a way to represent quantities using digits and a base. This course focuses on binary (base 2), octal (base 8), decimal (base 10) and hexadecimal (base 16).

WORKED EXAMPLE

Binary uses 0 and 1; octal uses 0–7; decimal uses 0–9; hexadecimal uses 0–9 and A–F.
