Hexadecimal Number System

Learn hexadecimal digits and their uses.

LEARN THE CONCEPT

Key idea

Hexadecimal is base 16. It uses 0–9 and A–F, where A=10, B=11, C=12, D=13, E=14 and F=15.

WORKED EXAMPLE

2A₁₆ = 2×16 + 10 = 42₁₀.
