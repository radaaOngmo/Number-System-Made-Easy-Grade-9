Octal Number System

Explore base eight and valid octal digits.

LEARN THE CONCEPT

Key idea

Octal is a base-8 system. Its valid digits are 0 through 7. Place values are powers of eight.

WORKED EXAMPLE

17₈ = 1×8 + 7 = 15₁₀.
